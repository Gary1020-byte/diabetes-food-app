# Diabetes Food App

A small project for planning diabetes-friendly meals: food entries with
carbohydrate/carb-count values, blood-glucose context, and simple daily
summaries.

## Status

Scaffold — the repository is public and the Orca project is registered.
Application code has not been written yet.

## Planned layout

- `app/` — application source
- `docs/` — design notes and data model decisions
- `data/` — seed/sample data used by the app

## Conventions

- Carbohydrates are tracked in grams; sugar alcohols are counted at half
  their weight.
- Every food entry records its glycemic impact estimate where known.
